# Love For Martin

A small static love note made by Mina for Martin.

This site does not need Laragon, a database, or a build step. It can be hosted
directly with GitHub Pages.

Public URL after GitHub Pages is enabled:

`https://minacomell.github.io/love-for-martin/`

Scan `assets/love-qr.png` to open the public website from a phone.

Optional files:

- Put the song MP3 at `assets/song.mp3`.
- Put slideshow photos at `assets/photos/photo1.jpg`, `photo2.jpg`, `photo3.jpg`, and `photo4.jpg`.
- Mina admin password is set in `script.js` as `ADMIN_PASSWORD`.
